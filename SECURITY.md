# Segurança

- Credenciais compartilhadas em conversas devem ser trocadas antes do deploy.
- Não abrir issues públicas com dados de acesso.
- Usar repositório privado durante o desenvolvimento.
- Usar Secrets no GitHub para FTP/SFTP/API.
- Desabilitar exibição de erros em produção.
- Forçar HTTPS.
- Trocar a senha administrativa padrão do MVP.
- Fazer backup do banco antes de toda migração.

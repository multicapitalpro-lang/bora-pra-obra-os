# Prompt mestre para iniciar no Claude

Leia integralmente os arquivos `CLAUDE.md`, `PROJECT.md`, `ROADMAP.md` e a pasta `docs/` antes de sugerir qualquer alteração.

Você continuará o desenvolvimento do Bora pra Obra OS. Não reinicie decisões de marca, stack, estrutura de pastas ou escopo já aprovadas. Primeiro faça uma auditoria do estado atual do repositório e apresente:

1. o que já existe;
2. o que está funcional;
3. o que está incompleto;
4. riscos de segurança;
5. a próxima tarefa única e concreta de maior impacto.

Não execute deploy, migração destrutiva ou alteração de credenciais sem confirmação. Trabalhe em branches pequenas, mantenha documentação e CHANGELOG atualizados e explique exatamente quais arquivos foram alterados.
